# Contributing

Each recipe is one Markdown file in `recipes/` with:

1. **Goal**: what you end up with.
2. **Prompt**: the exact prompt to paste, in a code block.
3. **Check**: how to confirm it worked.
4. **If it goes wrong**: common failures and the follow-up prompt that fixes them.

Only add recipes you've actually run. Say which Unity version and MCP server you tested with at the bottom of the file.
